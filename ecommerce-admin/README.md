# 现代化电商运营后台

一个面向真实电商场景的现代化运营管理系统。

## 技术栈

- **前端框架**：React 18 + Vite
- **样式方案**：Tailwind CSS + shadcn/ui 组件库
- **图表库**：Recharts
- **后端服务**：Supabase (PostgreSQL) + RPC 函数
- **认证鉴权**：NoCode 平台 SSO + 员工角色权限体系

## 功能模块

| 模块 | 说明 |
|------|------|
| 仪表盘 | 核心 KPI、待办事项、营收趋势、订单状态分布、热销商品、品类排行 |
| 订单处理 | 订单列表、状态流转、批量操作、物流信息、订单详情、新建订单 |
| 售后退款 | 售后单管理、退款审核、退货库存自动回补 |
| 商品管理 | 商品 CRUD、SKU 规格、库存同步、上下架 |
| 库存管理 | 库存总览、库存日志、采购入库、库存调整 |
| 商品分类 | 分类增删改查、排序、关联商品统计 |
| 供应商管理 | 供应商档案、联系人、合作状态 |
| 客户会员 | 客户列表、会员等级、积分管理 |
| 优惠券 | 优惠券创建、使用记录 |
| 数据分析 | 营收趋势、商品排行、自定义时间范围、CSV 导出 |
| 财务对账 | 收入汇总、退款记录、每日趋势、结算跟踪 |
| 账号管理 | 员工账号、角色权限 |
| 操作日志 | 全量操作审计 |

## 本地运行

```bash
npm install
npm run dev
```
