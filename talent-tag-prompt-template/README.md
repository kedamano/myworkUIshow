# 人才标签提示词模板 · 交互原型

智能打标平台 —— 标签管理模块的可交互原型。

## 功能概览

- **标签分类树**：K1 关键信息 / K2 关键经历等多级分类，支持过滤搜索
- **新建标签维度三步向导**：基本信息 → 关联字段 → 规则配置
- **场景模板库**：183 条标准口径，新建标签时一键填入描述
- **标签列表**：状态管理（启用中 / 已暂停 / 计算中）、覆盖与待复核统计
